# RPA Automation Projects

Repositório dedicado aos meus projetos pessoais de automação de processos utilizando Python.

O objetivo é desenvolver minhas habilidades em programação e aprender a automatizar tarefas repetitivas, organizar informações e melhorar processos por meio da tecnologia.

## Projetos

- **01. Organizador de arquivos:** automação para separar arquivos por extensão.
- **02. Automação de planilhas:** leitura, organização e processamento de dados.
- **03. Geração de relatórios:** criação automática de relatórios com dados de exemplo.
- **04. Automação de processos:** aplicação de regras de negócio em tarefas repetitivas.

## Tecnologias

- Python
- Git e GitHub
- Linux
- Bibliotecas de automação, conforme a necessidade de cada projeto.

## Objetivo de aprendizagem

Este repositório faz parte da minha jornada de aprendizado em programação, com foco em automação de processos (RPA), resolução de problemas e desenvolvimento de projetos práticos.

Os projetos serão adicionados e aprimorados conforme meus estudos avançarem.
